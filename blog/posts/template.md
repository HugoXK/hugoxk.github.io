Write your post in Markdown. This template is just a starting
point — copy it, rename it to `<slug>.md`, write your content,
then register the post in `js/blog-posts.js`.

## Sections

Use `##` for section headings.

Inline `code` works, and fenced code blocks:

```python
def hello():
    print("hello, blog")
```

> Blockquotes are useful for citing papers or tweets.

- lists work too
- [links](https://example.com) and images `![alt](path)` as well

Remember: the title/date/summary shown in the post list come from
`js/blog-posts.js`, not from this file.
